Jornada dos Sonhos began as an applied learning project: understanding how to guide language models, work with agents, and organize prompts so the technology can become a useful application rather than just a demonstration.

The application uses Streamlit and Ollama to build context from local data and documents, connect to locally hosted models, and apply structured system prompts. The work focuses on local privacy, context design, and assistant behavior.

The public repository remains the technical source for the current implementation.
