# 12. Performance

## Meta

A experiência inicial deve ser rápida e consistente.

## Diretrizes

- usar componentes leves
- limitar JavaScript ao necessário
- otimizar imagens
- evitar bibliotecas pesadas sem ganho claro
- preferir renderização simples

## Imagens

- formatos modernos
- tamanhos responsivos
- compressão adequada
- fallback correto

## Fontes

Carregar com parcimônia.

## Interação

Efeitos visuais devem ser baratos em CPU e GPU.

## Hosting

Cloudflare Pages deve hospedar a versão final com foco em entrega simples e rápida.
