## Como tratar currículos e projetos

- Currículos servem como base editorial.
- O GitHub serve como base técnica e de prova.
- O site deve preferir fatos recentes e explícitos.
- Se um dado existir apenas em uma versão antiga de currículo e não estiver confirmado no restante do contexto, manter como pendente.
- Detalhes de cargo, período e resultado só entram quando puderem ser confirmados na fonte original.

## Regra para casos ambíguos

Se a informação for pequena e necessária para o fluxo do site, decidir com base no contexto.
Se for importante para credibilidade, registrar como pendência.
