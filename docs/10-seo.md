# 10. SEO

## Objetivo

Garantir descoberta clara do site por nome, domínio, projetos e serviços.

## Prioridades

- marca pessoal
- domínio `cauarocha.dev`
- título profissional
- projetos relevantes
- Rocha Digital Studio

## Metadados

Cada página importante deve ter:

- title
- description
- canonical
- Open Graph
- Twitter card

## Estrutura semântica

- `h1` único por página
- headings consistentes
- links descritivos
- imagens com `alt`

## Schema

Aplicar quando fizer sentido:

- `Person`
- `WebSite`
- `ProfilePage`
- `CreativeWork` ou `SoftwareApplication` para projetos, quando apropriado

## Social cards

As imagens sociais devem refletir a identidade premium e pessoal.

## Conteúdo indexável

- home
- projetos
- serviços
- páginas de case
- currículo, se publicado como página
